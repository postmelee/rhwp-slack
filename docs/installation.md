# 설치 방식 선택

## 서버 운영 없이 사용하기

[공개 베타 홈페이지](https://rhwp-slack.pages.dev/)에서 **Slack에 추가**를 선택하세요. 구성원마다 앱을 만들거나 토큰을 운영자에게 보낼 필요가 없습니다.

1. 설치할 워크스페이스를 선택하고 요청 권한을 확인합니다. 조직 정책에 따라 관리자 승인이 필요할 수 있습니다.
2. 사용할 채널에 rhwp를 초대합니다. 처음 초대한 채널에서 자동 감지가 켜지며 기존 설정은 유지합니다.
3. HWP·HWPX를 올리고 같은 스레드의 PDF와 페이지 이미지를 확인합니다.
4. **rhwp에서 편집**을 누르고 Slack으로 로그인합니다. 브라우저에서 수정하고 **편집본을 Slack에 저장**을 누릅니다.

설정 관리자는 `/rhwp` 또는 앱 홈에서 자동 감지·멘션 요청·사용 안 함을 선택할 수 있습니다. 일반 사용자도 자신과 앱이 접근 가능한 문서를 열고 편집할 수 있습니다.

편집은 외부 브라우저에서 제공하며 Slack 내부 편집기는 공개 베타의 지원 범위에 포함하지 않습니다. 현재 무료 베타이며 Marketplace 등재는 아직 완료되지 않았습니다.

[사용 안내](https://rhwp-slack.pages.dev/guide/) · [개인정보 처리 안내](https://rhwp-slack.pages.dev/privacy/) · [지원](https://rhwp-slack.pages.dev/support/)

## 조직에서 직접 운영하기

조직이 소유한 Slack 앱·Google Cloud·Cloudflare 계정으로 서버와 편집기를 운영할 수 있습니다. 구성원은 조직의 Slack 앱을 사용하고, 조직 운영자가 비용·권한·토큰·업데이트와 장애 대응을 관리합니다.

[자체 호스팅 안내](self-hosting.md)는 Cloud Run과 Pages 구성 절차를 제공합니다. 원클릭 설치는 제공하지 않으며, 새 조직의 빈 계정에서 전체 절차를 재현한 검증은 남아 있습니다. Enterprise Grid 조직 전체 설치를 지원한다는 의미는 아닙니다.
