REVIEW WALKTHROUGH

설치부터 편집본 저장까지

rhwp의 사용 영상과 설치·로그인·저장 화면을 순서대로 안내합니다.

For Slack Marketplace reviewers: install rhwp in your own Slack workspace, invite it to a new channel to enable automatic detection, then preview and edit an HWP/HWPX document. No separate rhwp account or paid plan is required.

Slack에 추가

영상은 2026년 9월 26일, 아래 스크린샷은 9월 22일 공개 앱에서 촬영했습니다. 안내 문구는 현재 동작에 맞췄습니다. 설치·편집 로그인은 서로 다른 절차입니다. 이 자료는 심사 준비용이며 Marketplace 승인 여부를 뜻하지 않습니다.

65초 사용 시연

앱이 설치된 채널에서 문서 업로드 → PDF 확인 → Firefox에서 편집 → Slack에 편집본 저장까지 보여 줍니다.

Usage demo in Slack and Firefox. Installation, authorization and channel setup are documented in the screenshots below.

1. 워크스페이스를 선택하고 설치

Install and authorize

Slack에 추가를 누르면 Slack의 공식 설치 화면으로 이동합니다. 사용할 워크스페이스와 앱 권한을 확인하고 허용합니다. 현재 공개 베타이므로 Marketplace 미승인 안내가 표시됩니다.

2. 설치 완료 확인

Installation complete

설치 완료 화면이 나오면 Slack으로 돌아갑니다. 별도의 rhwp 계정이나 토큰 입력은 필요하지 않습니다.

3. 채널에 초대하고 동작 설정

Invite the app and configure a channel

새 채널에 rhwp를 초대하면 HWP/HWPX 파일 자동 감지가 켜집니다. 필요한 경우 앱 홈의 채널 설정 또는 /rhwp에서 멘션 시에만 동작으로 바꿀 수 있습니다. 이미 설정한 채널은 기존 설정을 유지합니다.

4. 문서를 열고 Slack으로 로그인

Preview a document and sign in to edit

설정한 채널에 HWP/HWPX를 올리면 원본 메시지의 스레드에 PDF와 첫 3페이지 이미지가 생성됩니다. PDF로 보기와 이미지 클릭은 Slack 뷰어를 엽니다. rhwp에서 편집을 누르면 별도의 Slack 로그인 화면이 열립니다. 문서가 있는 워크스페이스 계정으로 로그인합니다.

5. 브라우저에서 편집하고 저장

Edit in the browser and save to Slack

브라우저 편집기에서 문구를 수정한 뒤 편집본을 Slack에 저장을 누릅니다. 아래 화면은 합성 문서에 한국어 문구를 추가하고 첫 저장이 성공한 실제 결과입니다. 원본 파일은 덮어쓰지 않습니다.

6. 같은 스레드에서 결과 확인

View the saved document, PDF and images

Slack의 원래 스레드에서 새 편집본과 PDF·페이지 이미지를 확인합니다. 각각 준비되는 대로 표시됩니다. 아래는 저장된 첫 페이지 이미지를 Slack에서 연 화면입니다.

추가 확인

  • 4페이지 이상 문서는 추가 페이지 이미지 보기로 최대 10페이지를 확인할 수 있습니다.
  • 멘션 전용 설정에서는 파일이 있는 메시지나 스레드에서 @rhwp로 처리 요청을 보냅니다.
  • 앱 제거·재설치 후에는 새 요청으로 편집 연결을 만듭니다. 이전 설치의 편집 링크는 사용할 수 없습니다.
  • 최대 20 MiB·200페이지의 HWP/HWPX를 지원합니다. HWP3·암호화 파일은 지원하지 않습니다.

자세한 절차와 접근 오류 안내는 사용 안내, 문의는 지원 페이지를 확인하세요.
