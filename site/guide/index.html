GUIDE

처음 사용하는 rhwp

한 번 설치하면, 팀의 한글 문서를 같은 대화 안에서 확인할 수 있습니다.

1. Slack에 추가

Slack에 추가를 눌러 사용할 워크스페이스를 선택하고 권한을 확인하세요. 조직 정책에 따라 관리자의 설치 승인이 필요합니다. 별도의 rhwp 계정이나 토큰 입력은 필요하지 않습니다. 앱 이름은 rhwp입니다.

2. 채널에 초대하기

채널 세부정보 → 에이전트 및 앱에서 rhwp를 추가하세요. 비공개 채널도 가능합니다. 처음 초대한 채널은 자동 변환이 켜집니다. 이전에 설정한 채널은 기존 설정을 유지합니다. 동작 방식을 바꾸려면 설치자가 앱 홈의 채널 설정을 누르거나 /rhwp를 실행하세요.

  • 자동 변환: 채널에 올라온 HWP/HWPX 파일을 처리합니다.
  • 멘션할 때만 변환: 파일이 있는 메시지나 스레드에서 앱을 멘션하면 처리합니다.
  • 사용 안 함: 해당 채널의 문서를 처리하지 않습니다.

동일한 명령어를 가진 다른 rhwp 앱이 있다면 앱 홈에서 설정해 앱을 구분하세요.

3. 문서 확인

최대 20 MiB, 200페이지의 HWP/HWPX를 올리세요. 봇은 원본 메시지의 스레드에 PDF와 첫 3페이지 이미지를 게시합니다. 각각 준비되는 대로 갱신되며, 추가 페이지 이미지 보기로 최대 10페이지까지 볼 수 있습니다. 원본의 ‘이진’ 첨부 표시나 Slack의 이미지 배치는 바뀌지 않습니다.

4. 편집하고 같은 스레드에 저장

rhwp에서 편집을 선택하고 Slack으로 로그인하세요. 문서에 접근할 수 있는 워크스페이스의 계정을 사용해야 합니다. 브라우저에서 수정한 뒤 편집본을 Slack에 저장을 누르면 새 파일이 같은 스레드에 추가됩니다.

창을 닫거나 새로고침하면 저장하지 않은 변경은 사라집니다. 편집 연결은 10분 동안 사용하지 않거나 열린 지 1시간이 지나면 만료됩니다. 저장 중 만료 안내가 나오면 이 창을 닫지 말고 다시 로그인을 누르세요. 같은 계정으로 연결한 뒤 저장을 다시 시도할 수 있습니다. 로그인 창이 차단되거나 저장이 계속 실패하면 현재 편집본 다운로드로 파일을 보관하세요.

문제가 생겼나요?

앱의 채널 참여 여부와 채널 설정을 확인하세요. 접근 오류가 나면 올바른 워크스페이스로 로그인했는지 확인하고 Slack 카드에서 다시 여세요. 민감한 원본 파일 대신 발생 시각과 오류 문구를 지원 연락처로 알려 주세요.
