오류를 알려 주실 때

발생 시각과 시간대, 워크스페이스 주소, 어떤 버튼을 눌렀는지, 표시된 오류 문구를 알려 주세요. 화면을 보내실 때에는 민감한 내용을 가려 주세요. 비밀번호·토큰이나 업무 문서 원본은 보내지 않아도 됩니다.

무료 베타의 이용 범위

현재 사용자에게 이용 요금을 청구하지 않는 베타 서비스입니다. 제공 범위·운영 방식이 변경될 수 있으며, 응답 시간과 서비스 가용성을 보장하지 않습니다. 중요한 문서는 원본을 보관하고, 편집한 결과를 직접 확인한 뒤 사용하세요.

  • HWP/HWPX, 최대 20 MiB·200페이지를 지원합니다. HWP3와 암호화된 파일은 지원하지 않습니다.
  • PDF와 이미지는 Slack에서 확인하고 편집은 브라우저에서 합니다. Slack 내부 편집기는 공개 앱의 지원 범위에 포함하지 않습니다.
  • 한컴 프로그램과 모든 서식·출력 결과가 같다고 보장하지 않습니다.
  • Enterprise Grid 조직 전체 설치, Slack Connect의 조직 간 공유, 토큰 회전은 현재 지원 범위 밖입니다.
  • 이용 권한이 있는 문서만 처리하고, 조직의 보안·외부 서비스 이용 정책을 확인해 주세요.

앱 제거와 데이터 요청

Slack의 앱 관리 화면에서 제거할 수 있습니다. 앱 제거 후에도 Slack에 저장된 파일은 남을 수 있습니다. 서버 정보 삭제 요청은 이메일로 보내 주세요. 자세한 보관 범위는 개인정보 처리 안내를 확인하세요.

조직에서 직접 운영하고 싶다면

조직 소유의 Slack 앱, Google Cloud Run, Cloudflare Pages를 연결해 자체 호스팅할 수 있습니다. 관리자용 설치 문서를 준비했습니다. 브라우저 편집 방식으로 운영할 수 있으며 원클릭 배포는 아직 제공하지 않습니다. 현재 소스 저장소는 비공개이므로 문서와 소스·배포물 접근 조건을 이메일로 문의해 주세요.
