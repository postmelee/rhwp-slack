# Task #22 Stage 1 — 조직 소유 배포 문서

기존 내부 embed 전용 안내를 외부 browser runtime 기준으로 갱신했다. beta manifest, distributed 진입점, OAuth/OpenID callback, 설치별 암호화 키, 정확한 Pages/API origin, IAM·TTL·복구를 코드와 대조했다. 내부 main runtime은 별도 승인된 내부 앱 경로로 남겼다. 공개 지원 페이지는 준비된 문서와 비공개 소스 접근 문의를 안내한다.

별도 조직의 빈 계정에서 실제 배포한 것은 아니다. 원클릭 배포·소스 공개·라이선스 확정을 완료로 주장하지 않는다. 기존 운영 서비스는 변경하지 않았다.
