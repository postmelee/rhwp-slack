# Task #16 — 외부 베타 OAuth 설치와 워크스페이스 격리

Issue: [#16](https://github.com/postmelee/rhwp-slack/issues/16). M010.

## 목적

하나의 배포용 Slack 앱을 Add to Slack으로 설치하고, PDF·PNG는 Slack에서, 편집은 인증된 브라우저에서 사용한다. 기존 내부 워크스페이스의 C 운영을 보존한다.

## 배경·통합 기준

2026-09-20 PR #12 merge `59e9a02`, #14 merge `7de70dc`, #15 merge `a15f7d9`. 구현 기준은 `a15f7d9`다. #15의 원인 미확정 smoke timeout은 #17에서 추적한다. 재실행·최종 통합 CI 통과는 최초 원인 해결과 구분한다.

현재 Cloud 런타임은 고정 team/token 하나로 시작하고 Firestore namespace도 하나다. 기존 OAuth 설치를 흉내 내는 환경변수 목록 추가로는 격리를 보장할 수 없다. Slack 공식 OAuth는 앱 설치와 Sign in with Slack scope를 별도 흐름으로 요구한다.

## 범위

- 설치 레코드·암호화된 토큰·설치 generation 및 폐기 상태. 평문 토큰은 기존 일반 metadata 저장 경로에 넣지 않는다.
- 브라우저에 결속된 일회용 OAuth state, 명시적 redirect, 설치 응답 및 실제 bot 신원 검증, 취소·재사용·재설치·삭제/폐기.
- 검증된 Slack 요청에서만 tenant를 선택한다. 작업·편집 세션·문서·설정은 설치별로 격리하고 설치 generation이 바뀌면 기존 자격/세션을 다시 쓰지 않는다.
- 브라우저 편집용 사용자 인증은 설치 권한과 분리한다. 설치 사용자를 모든 문서의 사용자로 간주하지 않는다.
- Add to Slack 및 설치 후 채널 초대 안내. 별도 후보 환경·두 워크스페이스 수용 후 전환.
- Marketplace 심사·활성 설치 10곳 확보는 #4, 비용 관찰은 #3. 서버 사양·예산·upstream URL·저장소 공개 여부를 바꾸지 않는다.

## 설계·복구

기존 single-workspace 엔트리포인트는 기본값으로 유지한다. 새 경로는 명시적 별도 설정을 갖춘 후보에서만 활성화한다. 기존 Firestore namespace와 문서 연결을 migration으로 덮어쓰지 않는다. 토큰 암호화 키는 Secret Manager가 보관하며 애플리케이션 인증 정보와 분리한다. OAuth state는 서버 저장소의 원자적 consume 및 Secure/HttpOnly/SameSite=Lax 쿠키 결속으로 재사용·로그인 CSRF를 차단한다. callback 외부 URL/return URL을 사용자 입력으로 허용하지 않는다.

실제 운영 전환 전 현재 Cloud Run revisions/Pages deployment와 설정을 보존하고, 연결 주소 복구로 되돌릴 수 있도록 한다. Git 통합만으로 운영이 바뀌었다고 보고하지 않는다.

## 단계·검증 계획

1. 설치 저장·토큰 보호·state와 OAuth 경계: 실제 암호화/동시성/위조·취소·응답검증 단위 검사.
2. tenant 선택과 작업·세션 격리: 두 합성 설치의 동일 ID·삭제·재설치·큐 재전송·기존 경로 회귀.
3. 브라우저 편집 인증·Add to Slack: 설치 인증과 사용자 인증 분리, 만료/잘못된 사용자/워크스페이스 차단.
4. 별도 후보 환경: Linux CI, 기존 내부 회귀, 두 실제 워크스페이스 설치/변환/저장/삭제. 실제 앱 자격 증명과 검증용 workspace 확보 필요.
5. 문서·보고·단계적 전환: 정책·지원·권한 안내 및 복구. 미수행 실제 수용은 명시한다.

## 리스크·승인

외부 배포용 Slack 앱 자격 증명과 두 번째 workspace가 없으면 로컬 구현/CI와 실제 수용을 구분한다. 토큰 회전 기능을 지원하지 않는 단계에서는 회전형 응답을 안전하게 거부하고 지원을 허위 표시하지 않는다. 사용자 ‘권하는 순서대로 진행’ 지시로 계획·구현·검증을 진행하며, 외부 실제 앱 권한·비용·전환은 구체적 설정 준비 후 기존 승인 범위를 확인한다.
