기존 공개 사이트 export 검사와 데스크톱·모바일 하단 표시를 확인한다. 커뮤니티 문서와 함께 검토 가능한 로컬 변경으로 준비하며 Sponsors 계정의 정산·등급·결제 설정은 바꾸지 않는다. 후원 버튼의 실제 표시는 기본 브랜치 반영 후, 홈페이지 안내는 Pages 배포 후 확인한다.

## Stage 13 — 베타 모집과 커뮤니티 지원

2026-09-27 사용자가 추천한 README 모집 안내·Discussions 지원 창구 구성을 승인하고 적용을 요청했다. 기존 #4의 후속 작업으로 최신 devel에서 진행한다. README 상단에 초기 10개 팀 모집 목표와 설치·참여·질문 링크를 추가한다. 현재 활성 조직 수는 검증되지 않았으므로 0/10 같은 실적 수치나 참여 완료 표현은 쓰지 않는다. CONTRIBUTING과 GitHub 이슈 선택 화면은 사용 문의·아이디어를 Discussions로, 재현 가능한 버그는 Issues로, 개인정보·보안 문의는 기존 비공개 이메일로 안내한다.
