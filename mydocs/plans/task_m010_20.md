설치 OAuth 진입은 완료됐으나 Slack Direct Install 계약의 HTTP302와 현재303이 다르다. 사용자는 공개 베타 준비를 승인했다. #19의 OAuth 구현에 의존하므로 별도 worktree codex/public-beta-launch를 #19 head에서 시작한다. 선행 PR 통합 뒤 devel 기준 diff를 검토한다.
