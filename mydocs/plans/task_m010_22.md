# Task #22 — 조직 소유 인프라 설치 안내

기존 Cloud Run + Pages 자체 호스팅 문서를 실제 외부 browser runtime 기준으로 갱신한다. 별도 조직 앱·GCP·Cloudflare와 설치별 암호화 키, OAuth/OpenID, IAM·TTL·정적 공개 범위를 명확히 한다. 내부 embed runtime은 승인된 내부 앱에만 적합함을 구분한다. 자동 배포나 새로운 조직 계정에서의 실제 설치 성공을 주장하지 않는다.

공식 문서는 기존 docs/self-hosting.md와 site/support에 두며 작업 증적은 mydocs에 둔다. 비공개 저장소·배포물 접근과 라이선스 조건은 지원 연락처에서 확인하도록 안내한다. 자원을 추가 생성하거나 예산을 올리지 않는다.
