# Task #21 — 공개 베타 홈페이지와 운영 안내

## 목적·배경

사용자가 홍보할 수 있는 공개 베타가 이번 완료 목표다. Marketplace 제출과 embed 승인은 #4 후속이다. 운영자 Taegyu Lee, 공개 지원/삭제 요청 이메일 meleeisdeveloping@gmail.com은 사용자가 명시했다.

## 범위·설계

홈페이지/설치안내/개인정보/지원·이용안내를 정적 HTML로 제공하고 Add to Slack은 /install OAuth 시작으로 연결한다. 프로그램과 같은 Pages 배포에 공개 홈페이지를 포함할 수 있도록 옵션을 제공한다. 기존 내부 Pages는 기본옵션 유지. 외부 지원은 이메일이며 기존 private 저장소 링크를 일반 사용자 진입점으로 쓰지 않는다.

개인정보 문구는 실제 code의 document bytes 비영속 처리, Firestore 메타데이터/암호화 설치토큰, 논리만료/물리TTL 지연, uninstall 무효화와 수동 삭제를 구분한다. 무조건 즉시 완전 삭제나 모든 처리 로컬만 실행을 약속하지 않는다. 기존 사용자 문서·파일은 홍보 예시로 사용하지 않는다.

## 문서 위치·검증

공개 본문 site/ (HTML/CSS/로고), 제품 docs와 README, 작업기록 mydocs. 단계1구조/내용, 단계2빌드·라우트·문서, 단계3스크린샷/링크/보안/배포 검증. 새 공개 Pages 주소의 충돌을 먼저 확인하고 운영 내부 rhwp-slack-editor는 덮어쓰지 않는다. 서버 사양·권한·과금 변경 없음.

## 공개 주소 결정

사용자가 제안한 `rhwp-slack.pages.dev`를 공개 홈페이지 `/`와 편집기 `/editor/`의 후보로 선택한다. 내부 `rhwp-slack-editor.pages.dev`는 단일 내부 API origin으로 고정되어 있으므로 그대로 유지한다. 새 공개 Pages가 확보된 후 beta API의 EDITOR_ORIGIN만 전환하며, 기존 beta Pages는 복구용으로 보존한다.

## 2026-09-22 후속: 실제 화면 반영

사용자의 홈페이지 반영·Marketplace 자료 정리 진행 지시를 적용한다. 승인된 국립국어원 업무계획 문서의 실제 Slack 화면만 사용하며 원본 HWP/PDF/PNG, 사용자 세션·비밀값은 커밋하지 않는다. 홈페이지 자산은 기존 공식 루트 `site/assets/`, 제출용 캡처와 설명은 `docs/assets/marketplace/`와 기존 `docs/marketplace.md`에 둔다. 제품 소개 독자가 직접 보는 자료이므로 내부 조사 폴더 대신 기존 공식 루트를 사용한다. 이름 검증 증거와 개인 검증 로그는 공개 배포에 포함하지 않는다.

기존 #21의 미완료 소개 자료 범위로 진행한다. Marketplace 약관 동의·최종 제출은 #4이며 활성 설치 요건과 별개다. 편집기 프로그램을 재빌드하지 않고 검증된 동일 manifest 자산에 정적 홈페이지만 추가 배포한다.
