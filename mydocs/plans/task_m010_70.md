# Task #70 수행계획 — 실패 종료 처리와 진단 개선
GitHub Issue: https://github.com/postmelee/rhwp-slack/issues/70 · M010

## 목적과 배경
무효화된 카드의 실패 종료 bookkeeping이 일반 접근 검사에서 거절되어 반복 전달되는 경로를 수정한다. 접근 권한 검증과 저장소 일시 장애 재시도는 유지한다.

## 범위
종료 전용 lease 상태 판정, 고정 접근 거부 사유 진단, 최초/후처리 실패 구분, 기존 페이지 제한 안내 보강 및 회귀 검증. 엔진·제한 상향·권한 완화·실제 운영 데이터 공개는 제외한다.

## 설계 방향
종료 처리만 missing/removed/superseded를 안전한 skip으로 확정한다. 정상 문서 접근은 공통 보안 검사를 유지한다. 이벤트 진단은 allowlist enum만 포함한다. terminal 관측은 기존 원자적 중복 제거를 유지하며 5xx 감시를 묵음 처리하지 않는다.

## 문서 위치 판단
작업 산출물은 기존 mydocs/orders, plans, working, report에 둔다. 제품 안내는 기존 사용자 표시 문자열에서 개선하며 별도 문서 루트를 만들지 않는다. 비공개 배포 입력과 실제 워크스페이스 증적은 공개 저장소에 넣지 않는다.

## 단계 및 검증
1. 종료 처리 수정과 합성 경쟁/재전달/저장소 오류 테스트.
2. 접근 거부 진단과 제한 안내, 타입·단위·Slack·security 테스트.
3. 실제 테스트 워크스페이스 검증 후 배포 및 상태 확인. 별도 비공개 배포 입력·immutable rollback 유지.

## 승인
사용자가 권고대로 수정, 테스트 워크스페이스 검증 후 배포를 요청했고 추적 이슈 생성도 승인했다. 같은 범위에서 단계별 결과를 보고하며 진행한다. 검증 실패 또는 대상 불확실시 배포하지 않는다.
