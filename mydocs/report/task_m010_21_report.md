## 2026-09-22 후속 — 실제 화면 공개 반영

PR #27에서 합성 예시를 승인된 국립국어원 HWP의 실제 Slack 응답 이미지로 교체하고 모바일 확대 링크를 제공했다. Marketplace용 Slack 화면 3장, 브라우저 편집 보조 화면 1장과 소개문·재현 절차를 저장소에 보관했다. 공개 exporter는 홈페이지 JPEG 한 장만 배포한다.

검토·배포 source `9815658`, production Pages `0d4c8640`; 공개 페이지/설치 리디렉션/이미지 일치와 기존 편집기 유지 확인은 [Stage 3](../working/task_m010_21_stage3.md)에 기록했다. Linux viewer/container 통과.

홈페이지 배포는 완료했다. Slack 앱 설정의 새 긴 소개·지원 이메일·이미지 3장 저장 확인은 남아 있다. 브라우저 자동 입력 후 Save Changes 비활성화와 기존 2장 표시를 확인해 사용자에게 저장을 요청했다. #21을 닫거나 Marketplace 제출 준비 전체 완료로 보고하지 않는다. 실제 사용자·설치 철회 수용과 활성 설치/사용 요건, 최종 제출은 #4에서 계속 관리한다.

## 2026-09-22 후속 — 홈페이지 문구 명확화

사용자가 승인한 “한글 문서도 Slack 안에서 자유롭게” 제목과 자동 변환·한컴오피스 없이 열람·브라우저 무료 편집 설명을 적용했다. “자동 변환 합니다.” 표기는 사용자 요청을 그대로 사용한다. 제목 위 HWP · HWPX / SLACK을 제거하고 기능·시작 안내·푸터 제목도 완결된 문장으로 바꿨다. 한국어 단어 중간 줄바꿈을 줄이기 위해 홈페이지 본문과 제목에 keep-all을 적용했다.

기존 공개 exporter 검사 1/1 통과, 프로그램 버전 fb123639… 유지, 데스크톱과 모바일 390px 직접 판독에서 잘림·가로 넘침 없음. 이미지·설치 링크·서버 동작은 변경하지 않았다. 배포·최종 CI 결과는 후속 문구 수정 PR에 기록한다. Slack 설정 저장 대기와 Marketplace #4의 조건은 그대로 남는다.

## 2026-09-22 후속 — 사용자 제공 스레드 이미지

사용자가 제공한 1496×2120 PNG를 그대로 대표 이미지로 교체했다. 원본 업로드·완료 반응·PDF·페이지 이미지·편집 버튼을 함께 보여준다. 기존 JPEG 대신 새로운 PNG 경로를 공개 exporter에 등록하고 HTML의 크기·대체 텍스트·확대 링크를 맞췄다. 자르기·재생성·재인코딩 없이 원본 바이트 일치를 확인했다.

기존 공개 exporter 검사 1/1 통과, 69 files와 fb123639… 프로그램 버전 유지. 데스크톱·390px 모바일 직접 판독에서 전체 이미지가 표시되고 가로 넘침이 없다. 배포 결과와 CI는 후속 PR에 연결한다.

추가 사용자 요청에 따라 이미지 하단 설명과 “화면 크게 보기” 링크를 제거했다. 이미지 자체 클릭으로 원본을 여는 동작과 대체 텍스트는 유지한다. 사용하지 않는 캡션 CSS도 정리했다.

## 2026-09-22 후속 — 첫 화면 중앙 배치

헤더 높이를 데스크톱 72px·모바일 64px로 줄였다. 데스크톱 hero는 헤더를 제외한 화면 높이를 채우며 텍스트·이미지를 세로 중앙에 정렬한다. PNG 비율(1496/2120)과 화면의 남은 높이로 이미지 폭을 제한해 전체 이미지를 표시한다. 모바일은 단일 열의 자연스러운 문서 흐름을 유지한다.

Chrome 직접 판독: 1440×900에서 이미지 하단 866.58px, 1280×720에서 686.57px로 첫 화면 안에 들어온다. 두 크기에서 hero 하단은 각각 900/720px이고 텍스트·CTA도 화면 안에 들어온다. 390×844 모바일에서 가로 넘침 없이 표시되며 헤더 64px을 확인했다. 기존 공개 exporter 검사 1/1, 69 files와 fb123639… 프로그램 버전 유지. 매우 짧은 화면이나 모바일에서는 글자를 지나치게 축소하지 않고 세로 스크롤을 허용한다. 배포/CI 결과는 해당 PR에 기록한다.

추가 요청 반영: 이미지 컨테이너의 흰색 배경·테두리·둥근 모서리·외부 그림자를 제거했다. 데스크톱 hero 여백을 위아래 16px로 줄였다. 1280×720에서 이미지 높이는 581.15→615.98px, 하단은 686.57→703.99px로 커지면서 첫 화면 안에 유지된다. Chrome에서 배경 투명·테두리 0·컨테이너 그림자 없음과 모바일 가로 넘침 없음을 확인했다. PNG 원본에 포함된 창 그림자는 그대로 유지한다. 공개 exporter 검사 1/1와 69개 파일·기존 프로그램 버전 유지.

추가 공통 UI 정리: 네 페이지의 푸터를 “Slack에서 한글 문서를 확인하고 편집하세요”로 통일하고 지원 첫 문장의 운영자 소개를 삭제했다. 헤더 이름을 명시적 strong 요소로 감싸고 line-height:1 및 flex 중앙 정렬을 적용했다. Chrome에서 로고·이름·for Slack 중심 좌표가 모두 35.5px로 일치하고 네 페이지의 푸터와 가로 넘침 없음을 확인했다. 지원 페이지 모바일도 직접 확인했다. 조직 안내는 실제 저장소 공개 후 문서 링크를 연결할 후속으로 유지한다.
